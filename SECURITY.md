# Security policy

Context Archive stores agent session history, which can include credentials that
appeared in tool output, so security reports are welcome.

## Reporting a vulnerability

Please report privately through GitHub: on this repository, open **Security** >
**Report a vulnerability**. Do not open a public issue for a vulnerability.

Include what is affected, how to reproduce it and the impact you expect. You will get an
acknowledgement, and a fix or mitigation will be published with an advisory once it is
available.

## Supported versions

Only the latest commit on `main` is supported.
